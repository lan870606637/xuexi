# Python 字符串 replace() 方法详解

## 基本语法

```python
字符串.replace(旧字符串, 新字符串, 替换次数)
```

| 参数 | 说明 | 是否必须 |
|------|------|----------|
| 旧字符串 | 要被替换的内容 | 是 |
| 新字符串 | 用来替换的内容 | 是 |
| 替换次数 | 最多替换几次（默认全部替换） | 否 |

## 返回值

返回**新的字符串**，原字符串不会被修改（字符串是不可变的）

---

## 示例详解

### 示例 1：基本替换

```python
text = "hello world"
result = text.replace("hello", "hi")

print(result)   # 输出: hi world
print(text)     # 输出: hello world（原字符串没变）
```

### 示例 2：替换所有匹配项

```python
text = "苹果很好吃，苹果很甜"
result = text.replace("苹果", "香蕉")

print(result)   # 输出: 香蕉很好吃，香蕉很甜
```

### 示例 3：限制替换次数

```python
text = "aaa"
result = text.replace("a", "b", 2)  # 只替换前2个

print(result)   # 输出: bba
```

### 示例 4：原字符串中的空格不会被处理

```python
text = "  login Test  "
result = text.replace("login", "Logout")

print(f"'{result}'")   # 输出: '  Logout Test  '
# 注意：前后的空格还在，replace只替换"login"这部分
```

---

## 常见错误理解

### ❌ 错误理解 1：以为会改变原字符串

```python
text = "hello"
text.replace("hello", "hi")
print(text)   # 还是 "hello"，因为原字符串没变！

# ✅ 正确做法：把结果存到变量
new_text = text.replace("hello", "hi")
print(new_text)   # "hi"
```

### ❌ 错误理解 2：以为会模糊匹配

```python
text = "loginTest"
result = text.replace("login", "Logout")

print(result)   # "LogoutTest"（连在一起，不会自动加空格）
```

### ❌ 错误理解 3：以为会去掉空格

```python
text = "  hello  "
result = text.replace("hello", "hi")

print(f"'{result}'")   # '  hi  '（空格还在！）

# ✅ 要去空格用 strip()
result = text.strip().replace("hello", "hi")
print(f"'{result}'")   # 'hi'
```

---

## 常用搭配

### 替换 + 去空格

```python
text = "  login Test  "
result = text.strip().replace("login", "Logout")
print(result)   # "Logout Test"
```

### 替换 + 转小写

```python
text = "LOGIN Test"
result = text.lower().replace("login", "logout")
print(result)   # "logout test"
```

### 删除某个字符（替换成空字符串）

```python
text = "hello-world-test"
result = text.replace("-", "")  # 把横线删掉
print(result)   # "helloworldtest"
```

---

## 总结

| 你要做什么 | 代码 |
|-----------|------|
| 替换所有匹配 | `text.replace("a", "b")` |
| 只替换前N个 | `text.replace("a", "b", N)` |
| 替换后去空格 | `text.strip().replace("a", "b")` |
| 删除某个字符 | `text.replace("x", "")` |
| 保存结果 | `new_text = text.replace("a", "b")` |
